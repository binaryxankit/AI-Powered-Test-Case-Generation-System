# Sample Screenshots

Drop screenshots of the running application here to support documentation,
demos, and submissions.

Recommended filenames:

- `home.png` — Landing page (hero, features, how-it-works).
- `generate.png` — Generator page (textarea with sample prompt loaded).
- `loading.png` — Loading spinner state during AI generation.
- `results.png` — Results page showing the generated test case cards.
- `history.png` — History list with previous generations.
- `history-detail.png` — Re-opened generation showing all cards.
- `dark-mode.png` — Dark mode home page.
- `mobile.png` — Mobile responsive view.

PNG, JPG, or WebP are all fine. The application itself does not read or
serve these files; they are for documentation purposes only.
